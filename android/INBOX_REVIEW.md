# 小组件待确认列表

点击桌面小组件的“待确认 N 条”进入收集箱列表。每条信息展示标题、时间提示、正文摘要、地点和来源，并提供三个入口：

- 原文：查看完整通知与附图。
- 修改：打开现有核验编辑页，保存后返回列表；直接返回不会确认。
- 确认：按已有信息加入日程或候选指定的待办、课程、长任务，无需先进入编辑页。未填写具体日期时保留时间待定。

确认后保留原记录 ID、完整正文、附件和来源，更新修订并刷新提醒和小组件数量。已更新、已删除或已处理的信息不能被旧列表覆盖；时间有误时提示先修改。列表每页 50 条，返回时保留页码与滚动位置，末页处理完会回到有效页。

本次源码与测试改动均位于 `android/`。

## 验证

安装 JDK 17、Gradle 9.6.1、Android SDK 36 后，在 `android/` 运行：

```powershell
gradle :app:compileDebugJavaWithJavac :app:testDebugUnitTest :app:lintDebug
```

`InboxReviewTest` 覆盖完整正文与附件、时间待定、版本冲突、重复确认、无效时间、冷启动与已有页面的小组件入口、取消与保存编辑、列表内确认、分页及末页回退。

本次验证结果：Java 编译通过；8 项 Robolectric 测试全部通过（Android 9 / SDK 28）；Lint 与原始 `main` 均为 20 个错误、100 个警告，逐项对照没有新增问题。本机仅在验证配置中跳过未修改的语音 CMake 库构建，未做完整 APK 打包或真机测试。

真机检查：

1. 收集两条以上通知，分别在应用关闭和已有编辑页时点击小组件“待确认”，均应打开列表。
2. 对一条信息点“确认”，应留在列表并减少一条；回到桌面，小组件数量相应减少。对另一条点“修改”，保存后回到列表；取消编辑则仍在待确认列表。
3. 检查长正文、附图、模糊时间和超过 50 条信息的分页；旋转屏幕或从核验页返回时，检查所在页和滚动位置。
