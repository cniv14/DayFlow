# Android 1.3.0 · 统一 Agent

本版以主界面固定的“问日栖”入口为中心。助手是可选独立APK，安装后从日栖直接使用；本地日程、笔记和同步无需AI或注册。

## 安装与使用

覆盖安装 DayFlow-android.apk；使用Agent时再覆盖安装 DayFlow-assistant.apk。完整Markdown用户同时更新 DayFlow-markdown.apk。插件没有独立桌面入口，不需要额外登录。

在设置→Agent模型配置选择厂商、填写模型与API Key。模型需兼容Chat Completions并支持工具调用；课表截图需视觉模型。点击主界面底部醒目的“问日栖”，可输入“明天9点开会，持续1小时，提前10分钟提醒”等请求。Agent可查询安排、搜索笔记、创建待办/笔记、收集待确认信息、生成课表草稿。成功执行的结果会显示卡片并进入原同步队列，可撤销本次创建；已被手动编辑的记录不会被撤销覆盖。网络中断时先核对已创建的卡片，避免重复发送。

语音按钮调用手机已有语音识别服务，识别结果先填入输入框，修改后再发送；未安装识别服务可直接打字或使用键盘麦克风。插件没有常驻服务、录音轮询或HTTP监听端口。去掉蓝心小V/小爱授权、开放API密钥与相关设置，旧桥接入口关闭。

## 统一收集与人工核验

短信合并到设置→通知收集。统一控制总开关、全部内容/日程关键词、全部应用/指定软件、选中会话和正则。授予通知访问后，可从已收到通知发现的QQ、微信、TIM会话中选群；系统只给标题时列表也可能含私聊，需核对。筛选影响后续通知，原收集项保留。不读取历史聊天、静音时未生成的通知或历史短信。

短信接收权限为可选；默认短信应用也可作为通知来源。取件码、话费信息继续本地识别。直接接收短信开启且权限有效时，短信应用通知跳过，避免同时采集两份。所有信息先进入收集箱。

正则包含与排除均支持每行一个表达式；包含命中任一行即可，排除优先。作用于标题、会话、发送者与正文。空包含表示不额外限制；仍需满足应用/会话/全部内容设置。使用RE2/J，避免回溯型正则阻塞收集线程；支持常用分组、数量词、`|`和`(?i)`，不支持环视或反向引用。配置中可本地预览规则，预览不联网。

收集箱→一键AI总结，选择要整理的信息后交给同一个Agent；单条通知也可直接交给日栖整理。**本体强制这些会话生成inbox/pending，不能直接写入正式日程。** 原始资料保留，可在核验编辑中查看；逐项修正日期、地点、提醒后点击“已核验，加入日程”。没有自动确认或后台上传。

课表截图识别复用同一个Agent模型与工具，写入课表草稿；返回表格校正课程、星期、节次、单双周等，人工确认后才创建课程。没有提供结束时间时可留空，已知时长可使用持续分钟。

## 笔记与插件连贯体验

本体恢复基础Markdown预览：标题、列表、引用、代码、链接、粗斜体、删除线、复选框，源码编辑/字号/撤销/保存/导出始终可用。默认文件名为日期，原文不因缺少插件被改写。

安装并启用Markdown插件后，编辑笔记自动进入完整编辑器，不必再手动找插件入口；扩展中心可关闭自动调用。插件跟随本体深浅主题、强调色、字号和紧凑布局。保存写回同一篇笔记并同步，返回仍留在这篇笔记；系统.md授权继续保留。完整表格、图片、脚注和公式在插件内，格式按钮只在顶部，底部工具栏保持移除。

## 资源与兼容

通知事件驱动，单一工作线程和有界队列，空闲线程退出；正则按配置缓存，应用选择分页。AI只在用户主动操作时运行，长请求/响应经临时文件传递，API Key保留在本体。对话保留最近32轮本机缓存，发送模型最近8轮与本次选择资料；聊天缓存不作为业务记录同步，创建的日程/笔记正常同步。正式笔记仍无固定字数/文件大小配额，受设备物理资源约束。

服务端源码、消息类型和Windows程序不修改，保留原云同步、局域网、文件同步及TaskFlow Windows适配。本版只编译签名打包，不运行测试、Lint、模拟器、实机或真实AI请求；交互、识别与联通由用户实测。
