# 问日栖

主界面底部固定入口，文字和语音共用一个可选助手插件、一套模型配置、一组业务工具。只安装本体也能离线使用基础功能。

可以这样说：

- 明天上午九点开会一小时，在教学楼203，提前十分钟通知我。
- 看一下周五有什么安排。
- 记一条笔记：今天完成了项目第一阶段。
- 先收集下个月可能参加的活动，时间还没定。

自己的明确创建请求可以直接执行；成功后看结果卡，时间有误可返回日程编辑或撤销本次创建。语音识别后可修改文字再发送。

通知、短信、群聊和课表整理：在收集箱选择信息，或在课表选择截图，交给同一Agent。它们必须先生成待确认项/课表草稿，人工修改并确认后才进入正式日程。Agent不能绕过这个宿主规则。原文与AI候选分开保留。

模型需要支持OpenAI Chat Completions兼容的工具调用；图片需要视觉能力。没有配置AI Key、服务不支持工具或网络失败时，界面显示错误；不把纯文字回复当成创建成功。已执行的操作保留，重试前先核对。

插件不连接厂商语音助手，不开放HTTP端口，不常驻录音。Android语音识别由手机已安装服务提供，其联网/离线能力取决于该服务。文字聊天和资料会发送至用户自己配置的AI服务。
