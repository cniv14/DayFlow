# Android 0.3.0：开源组件复用、笔记与统一待办

本次重点仍在 Android。保留原应用 ID、签名、离线数据库和同步文件格式，可覆盖安装0.1.0／0.2.0。

## 直接复用的组件

- **Kizitonwose Calendar View 2.6.2（MIT）**：月历翻页、日期布局和单元格复用。在编辑日程／课表页面点“选择日期”进入月历，左右滑动选月份，日期下显示农历、节气或传统节日，有未完成安排时显示数量标记。
- **lunar-java 1.7.7（MIT）**：离线计算农历、干支、生肖、节气和传统节日。当前页面没有接入调休班表、宜忌或学校校历。
- **Markwon 4.6.2（Apache 2.0）**：原生 TextView 渲染 Markdown，不使用 WebView。第三方许可证随 APK 一起提供，项目原创代码保持 MIT。

## 笔记

支持原有文字和压缩图片笔记，新增搜索、置顶和 Markdown 展示。编辑笔记时可用“标题／加粗／列表／引用／代码”辅助插入格式，再进入预览。置顶状态、Markdown 正文与附图都是记录字段，可跨设备同步，Windows 保留正文原文。

## 课程是每日待办的一种

首页只显示今天的课程、日程、任务与阶段事项，统一放在每日清单中，支持勾选及恢复；完成某一节课不等于完成以后所有课程。首页不显示远期事项，也没有24小时空白时间轴。

首页右上角“编辑日程”进入独立表格，按实际存在的事项逐行列出，按日期分组，显示时间和名称，不预设空白时段。标题可直接修改，点时间进入完整编辑，切换日期或返回时保存标题。每页最多30行，时间列约86dp，其余宽度给标题，行高至少76dp。

底部“课表”提供专用编辑入口与 CSV／ICS 批量导入。课表和每日清单操作同一条记录、同一 ID，编辑和同步不会另建重复课程。

## 所有业务内容统一同步

同步覆盖：文字／图片笔记、置顶、日程、待办、课程、收集箱、阶段任务、重复规则、完成状态、删除标记与冲突副本。

- **文件**：设置 → 数据与同步 → 导出／合并导入，离线可用，无需账号。
- **局域网／云端**：设置服务器地址与账号。新登录后默认启用自动同步；已有登录用户可在设置手动打开开关。
- **自动同步**：数据变化后提交短时系统作业，网络可用时处理；系统另以最短15分钟周期调度。没有常驻同步进程，省电策略可能延后。局域网若被系统判为无互联网，可用“立即同步”。
- **手动同步**：随时点“立即同步”。设置显示上次成功时间及错误状态。

API Key、登录令牌、系统权限、壁纸、天气位置等设备配置不进入同步文件。文件同步为明文，账号仍各设备独立登录。

图片已内嵌在记录中。Android 与 Windows 上传改为每批最多20条，服务端增量下载按512KiB分页，减少图片笔记集中同步时的内存与响应大小。单条记录上限仍为64KiB；图片沿用压缩保存，文件导出仍有安全体积上限。

## 配套下载

本版 Windows 只更新同步批次与版本号，界面保持现有挂件。服务端提供本次分页修正，请保留原数据库卷并替换代码／重新构建镜像。

两端继续使用签名更新清单。云服务器可发布签名安装包，Android 安装仍由系统确认。
