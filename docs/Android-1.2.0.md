# Android 1.2.0

本版重点更新 Android，保持原有 DayFlow 云端、文件同步及 TaskFlow Windows 协议适配。Windows 程序未修改、未重新构建。支持本地使用，不要求注册或配对。

## 今天、周预览与日程

底部顺序为今天、笔记、日程、收集箱、设置，只显示图标，透明背景随主题取色。主页面支持横向滑动和轻量切换动画；从今天向左进入未来七天预览，再进入笔记。编辑器、横向滚动区域和滑块不抢滑动手势。系统关闭动画时尊重系统设置。

日程首先显示紧凑月历、农历与调休标记，选择日期查看当日任务、天气入口及编辑入口。课表移到日程二级菜单；黄历由可选黄历插件提供，未安装时本体仍显示农历和调休。2026调休数据随包提供，其他年份可以手动更新；没有数据的年份按普通周末处理，不能当作官方调休表。

长按待办可提前/延后30分钟、延后1小时、自定义分钟、移动日期或编辑。仍支持仅开始、开始加持续时间、开始加结束，结束可留空。地点按钮跳转高德地图，未安装时打开网页搜索，不内置地图SDK。

天气由Open-Meteo提供，按位置缓存最多16天日预报；周预览显示缓存天气、温度及降水概率。需要位置或手填坐标并刷新，缓存注明时间；无预报的日期不会猜测天气。黄历为传统历法信息。

## 收集与课表

设置中的短信收集默认关闭。授予接收短信权限后，本地规则提取新短信中的快递取件码、话费与欠费通知，保存为待确认收集项，小组件可显示待确认数量和最近内容。不读取历史短信；系统不授权时可以使用短信应用通知或粘贴。银行验证码不作为取件码收集。QQ/微信指定群通知筛选沿用原有设置。

AI截图课表先用原生控件裁剪、旋转，再明确发给自己配置的识图模型，识别后编辑确认。可选离线OCR作为独立APK安装：设置→扩展与存储→选图识别，文字进入收集箱；离线OCR是文字识别，不承诺自动还原任意课表的结构。

新增公开网页、HTML表格和ICS导入。jsoup只解析页面，不执行脚本、不登录学校账号；已知列名的标准表格可转换为课表，合并单元格、复杂周矩阵需人工/AI校正。ICS使用biweekly处理折行、时区和重复，单次导入展开过去30天至未来367天，最多4000次；拒绝复杂RECURRENCE-ID覆盖以免误导，不是持续订阅或完整CalDAV。

## 笔记

本体保留轻量纯文本/Markdown源码笔记、撤销重做、系统.md关联、导入及导出；完整Markdown编辑/预览单独安装DayFlow-markdown.apk，从笔记顶部入口打开。插件只获得本次文档临时授权，保存时由本体核对修订和文件摘要并进入同步队列。新建笔记及无标题导出默认使用YYYY-MM-DD，导入保留文件名。保存、导出和所有格式按钮只在顶部，移除了底部格式工具栏，按钮横排。Aa调节编辑/源码/预览字号12–32sp。

移除单独的公式按钮，**保留行内及块级LaTeX公式渲染**。预览支持标题、粗体、斜体、删除线、有序/无序列表、任务列表、引用、围栏代码、表格、链接、图片、基础HTML及脚注；源码可以保留其他Markdown扩展，不认识的语法不靠富文本往返重写。复杂内容自动使用源码编辑。代码保留等宽显示，暂不提供语法高亮和可执行图表。

图片加载有超时、采样解码和8MiB内存缓存；HTTP仅允许本地地址，远程使用HTTPS。网络图片需要联网；外部相对路径图片不自动获取文件夹授权或打包，文件导出也不自动下载远程附件。取消单篇48KiB、记录64KiB、草稿320KiB及同步文件4/16MiB等固定大小上限。文档本身不按字数或大小截断；列表读取摘要，打开时读取全文，SQLite正文分段读取以避开CursorWindow单行限制，文件同步逐条处理。撤销使用差量记录，大范围修改暂存私有缓存，避免反复保留整篇副本。超大文档仍受设备可用内存、存储及外部客户端能力影响，不承诺物理资源无限。

笔记详情可将Markdown勾选项提取为待办，相同来源不重复创建。已关联的原始行与文本仍匹配时，任务完成和笔记勾选可相互更新；移动/改名后保留内容，避免猜测并覆盖。

## 长期任务与轻量工具

长期项目有今日打卡、补卡、撤销、累计/连续统计和目标天数；每日记录是独立笔记，参与原有同步。项目看板分待开始、进行中、已完成。专注计时1–240分钟，可关联任务，后台靠系统闹钟调度，结束保存投入时间笔记，不常驻逐秒唤醒。

## 主题、插件与占用

壁纸取色读取应用实际选中的背景，Android12+应用Material动态配色；也可选系统动态色或手动主色。底部图标和小组件跟随强调色；旧版Android仍使用原生主题回退。

大型功能通过独立APK及受限Intent协议扩展，见插件API.md。完整Markdown、黄历、离线OCR、助手HTTP API均可按需安装，基础日程/笔记/农历/同步不依赖插件。插件使用独立进程；全部安装会有各APK基础库的重复开销，按需安装有助于节约占用。离线OCR分arm64与armv7两个包，不将模型塞入主程序，不提供x86包。插件识别完成后退出自身进程释放模型；主程序不加载下载的dex。下载后由系统安装器确认安装，OCR/通用识别结果需要确认；Markdown编辑是用户主动保存原笔记，助手API只有用户开启并授权密钥后才可创建事项。

设置提供存储统计和缓存清理；不会清除笔记、打卡、草稿或同步删除标记。裁剪图片超过24小时后在后续裁剪时清理。OCR模型占用由独立插件卸载释放。仅主程序与数据使用时无需安装OCR。

## 助手API与同步

设置→开放API与语音助手，默认关闭，密钥仅在本机保管。可使用原生ContentProvider接口；HTTP需要DayFlow-assistant.apk，手动开启前台桥接，监听127.0.0.1:8766，使用Bearer密钥，通知中可停止。支持能力查询、今日安排、笔记搜索、收集、新建笔记/待办和幂等完成；提供OpenAPI描述，见助手API.md。蓝心小V/小爱同学需要对应的自定义工具或自动化桥接能力，未接入厂商专有SDK，不声称已直接联通。

服务端v1继续采用账号隔离、UUID、服务端CAS版本、游标分页和删除标记，未知扩展字段原样保存，不为每个插件改变接口。认证同步不再有固定请求/单条记录大小配额；分页目标仍用于控制每批内存，单篇大笔记可独占一批。必须更新一次配套服务端以使用大记录，管理员可自行配置部署限额，默认0。旧客户端自身限制不能由Android强行取消。

修正连续修订误判冲突：远端修订是本地祖先时仅推进base_version后继续上传；远端包含本地修订时接受较新记录；真实并发或历史不足才保留副本。已有副本不静默删除，设置→数据与同步→查看与处理同步冲突可比较并保留原记录、副本或两份。涉及真实双端合并仍需用户实测。

配套backup.py使用SQLite在线备份接口，服务端稳定协议和迁移规则见服务端稳定协议.md。后续插件优先使用现有通用Record/扩展字段，不随UI调整修改服务端。
