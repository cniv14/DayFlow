# 统一更新与语音模块

从Android 1.3.2起，设置→统一更新负责主包、功能模块、原生引擎与模型的分发来源。GitHub目录默认`https://github.com/cniv14/DayFlow/releases/latest/download`，也可填写自己的附件目录。服务端使用当前日栖服务器与现有登录令牌；不会把令牌发给GitHub，不跨来源回退。

## 架构

助手、Markdown、黄历、语音转换为Android library，随本体提供可用基础版本。共享Material、Markwon、lunar等依赖与资源，避免多个独立APK重复存储。基础包不携带Whisper原生引擎或模型。插件代码包只含自己的DEX；运行时按签名验证后加载，固定的非导出Activity由宿主组件工厂实例化，保留Android生命周期和原生UI。Android 9+支持此路径，Android 8回退内置功能。

签名外层与原有更新一致，模块payload字段：`schema=1,platform=android-module,api=1,id=assistant|markdown|almanac|voice,version,version_code,min_app_code,max_app_code,sha256,dex(base64)`。当前模块修订号132001对应1.3.2-r1，基础版本132。必须单调递增并匹配基础版本范围；资源ID、公共依赖和原生ABI由基础版本提供，不可通过代码包任意增加权限或资源。升级基础包后不兼容的旧补丁会回退内置实现。当前/上一份签名包和下载高水位在设备本地保存，不进入用户同步数据。

更新设置常驻基础包；模块异常恢复内置版本。回退不会被同修订自动覆盖，后续发布需增加模块修订号。更新不强行关闭当前编辑器，退出重开对应功能后生效。自动检查由系统每12小时调度，无常驻下载轮询；不会静默安装主包APK。

## 服务端接口

`GET /v1/updates/<name>`，Bearer鉴权。允许文件名为`android-update.json`、`DayFlow-android.apk`、`runtime-update.json`、`assistant-module.json`、`markdown-module.json`、`almanac-module.json`、`voice-module.json`、`voice-engine.json`、`voice-engine-arm64.zip`、`voice-engine-armv7.zip`、`voice-model.json`、`voice-model.bin`。所有文件放在`DAYFLOW_UPDATES_DIR`目录；目录已在Docker以只读方式挂载，不需为发布文件重启服务。

旧`/v1/runtime-update`仍兼容；旧`/updates/`白名单保留但现在也必须登录。所有分发路径共享按账号持久化的请求额度，默认`DAYFLOW_RUNTIME_REQUESTS=10`、`DAYFLOW_RUNTIME_WINDOW_SECONDS=3600`，多设备共享；401需登录，404未部署，429附Retry-After。一个完整检查通常请求四个模块及主包清单，启用主界面覆盖时再增加一个请求，模型/引擎下载按清单和文件分别计数。管理员可提高额度，Android不会自动转GitHub规避限流。

## 语音

扩展与存储→语音识别配置，或助手麦克风进入同一模块。提供系统服务、百炼API、本地Whisper。百炼可以配置独立API Key（Keystore加密）、兼容接口根地址、模型名。默认`https://dashscope.aliyuncs.com/compatible-mode/v1`与`qwen3-asr-flash`，也支持官方工作空间专属域名；API Key应与地域和语音服务匹配。官方接口以input_audio/data URL上传WAV，本实现不执行CLI。参考[百炼官方文档](https://help.aliyun.com/en/model-studio/qwen-asr-api-reference)。

本地采用[MIT whisper.cpp](https://github.com/ggml-org/whisper.cpp) v1.9.5、固定提交`d1be6fde11ac6e0407606b4e42fe72d34add8037`。先下载本地识别引擎，再导入多语言tiny/base GGML模型；不要导入`.en`模型。可参考[官方Android示例](https://github.com/ggml-org/whisper.cpp/tree/v1.9.5/examples/whisper.android)与[官方转换权重](https://huggingface.co/ggerganov/whisper.cpp)。权重需遵守其上游许可，本次未附带。

录音为16kHz单声道，单次最多两分钟，离开页面停止录音；本地识别按需加载、最多4个线程并在结束后释放模型，不自动转云端，不记录原音到笔记或同步。临时WAV在操作结束删除。识别结果先填入对话输入框，不自动执行任务。引擎签名清单同时校验压缩包与展开库的长度/hash，文件位于应用内部只读路径；模型签名清单校验512MiB内的资源文件，下载成功前保留旧模型。引擎如已载入，升级后重启应用生效，不重装APK。

## 打包

先`python tools/fetch_whisper.py`准备固定源码；Android使用本机JDK17、SDK36、NDK28.0.13004108及CMake3.31.6。构建`:app:assembleRelease :app:exportModuleClasspath`，不需要构建独立插件APK。

`tools/package_feature_modules.py`从四个AAR生成签名代码包；`tools/package_voice_engine.py`从语音AAR抽取、剥离调试符号并按架构压缩签名；`tools/publish_voice_model.py`按需为管理员自己的GGML模型生成签名清单。签名操作只在维护者电脑执行，私钥不放到服务器。`tools/package_android_release.py --embedded-modules --skip-ocr --refresh-server`复用原Windows包并整理附件。基础APK有默认功能，即使模块服务未部署也能使用。
