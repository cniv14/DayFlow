# Android 0.2.0 界面与操作更新

本次重点修改 Android。Windows 和服务端继续使用0.1.0，数据文件与同步接口兼容。

## 日程怎么用

- 首页是周时间表；“日 / 周”切换视图，左右箭头切换日期，“今天”回到当天。
- 点击日期标题可打开原生日期选择页。
- 点击空白时间格，直接创建该时段的日程；点击已有色块查看详情。
- 编辑使用完整页面。时间由原生日历和时钟选择，不再手工填写 ISO 日期字符串。
- “待办”入口分为待完成、时间待定和已完成，支持直接勾选及恢复。
- 课表使用同样的周表格，右上角“导入”打开 CSV / ICS 文件，确认预览后导入。

## 笔记与收集箱

笔记以文字记录为主，日期和提醒设置在笔记模式下隐藏。通知打开后可以直接“确认并安排时间”，或进入 AI 提取页，将一条通知拆成多条待确认事项。编辑、设置、导入预览和更新说明都使用原生完整页面。

## 桌面小组件

设置 → 桌面小组件 → 添加到桌面。在启动器中确认添加。也可长按桌面，通过系统小组件列表添加“日栖 · 近期日程”。

组件展示近期安排与已缓存天气；点击事项打开详情，点击“○”标记完成，点击“＋”快速新建。缩放后按可用高度显示1–3条，适配浅色和深色主题。首次天气需要先在应用内获取。

## 深色与动态强调色

设置 → 外观与主题，可选择跟随系统、浅色或深色。

Android 12及以上可启用“使用系统动态强调色”，配色来自系统壁纸主题。Android 8–11使用日栖的备用配色。自定义壁纸、模糊、动态流光仍保留，动画只在前台运行。

## 自动位置天气

首页天气入口或设置 → 位置与天气 → 使用当前位置获取天气。系统会请求大致位置授权，坐标仅用于天气，不持续进行后台定位。允许自动刷新后，打开应用时缓存超过6小时才获取位置并刷新。

定位失败、未授权或设备缺少网络定位服务时，可搜索城市并选择天气位置；其他离线功能不依赖位置权限。

新版沿用原发行证书和应用 ID，可覆盖0.1.0。数据库提供原地迁移，事项、账号配置和 API Key 保留。建议更新前导出同步文件备份。
