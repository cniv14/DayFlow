# Android 1.3.1 · 合并更新与提醒改进

本版基于合并提交 b049cb6，重新构建 Android 本体及可选插件。原有数据与签名保持兼容，可直接覆盖安装。

## 本次更新

- 今日清单与桌面小组件统一显示当天安排、进行中的长任务、时间待定与已到期未完成待办；不重复创建事项，不给无时间任务虚构时段。未来尚未开始的长任务及等待前置条件的事项不提前显示。

- 改进更新包下载、缓存与待安装状态恢复，完善返回应用后的安装处理。
- Agent 助手支持选择图片作为输入，消息支持 Markdown 显示；图片理解需要配置支持视觉的模型。
- 调整闹钟与提醒处理，增加提示音回退及播放资源清理。

## 安装

安装 DayFlow-android.apk；使用助手时同时更新 DayFlow-assistant.apk。Markdown、黄历插件按需覆盖安装。本次暂缓发布离线 OCR 插件。已发布 Android APK 版本为 1.3.1，版本号为 131。

本地基础日程、笔记和文件同步仍无需注册或联网。通知整理及课表生成保留人工核验步骤。基础使用说明见 [1.3.0](Android-1.3.0.md)。

服务端和 Windows 沿用上一版原包，协议不变；Windows 的实际版本仍为 0.3.0。

本次只编译、签名并核对安装包版本及文件完整性，未运行自动测试、Lint、模拟器或真机验证；交互与设备兼容性由用户实测。
