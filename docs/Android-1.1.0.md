# Android 1.1.0：操作与资源完善

这是按用户要求顺序发布的第三个版本，承接0.5.0及1.0.0，不修改Windows端。

## 主要变化

### 笔记草稿保护

正文编辑停止约1.6秒，或应用进入后台时，保存一份私有草稿。草稿不自动写回外部`.md`文件，也不冒充已经保存／同步的正式笔记；编辑区显示“手动保存后同步”。手动保存成功后清除对应草稿。

笔记列表显示“恢复本机草稿”。原笔记从其他设备更新时，恢复为独立副本，避免覆盖新内容。最多保留30份，每份上限320KiB；达到上限时提示整理，不自动删除旧草稿。写入使用单线程、有限队列，空闲后退出。

### 近期展开、远期折叠

“今天 → 搜索、项目与全部安排 → 近期展开／远期折叠”。未来7天展开，更远按周／月折叠，只在展开时创建组内条目视图。无日期事项单独保留，首页仍只显示今天。

远期组只保留标题与日期等简要引用，不长期持有每条事项的图片／全文。点击后重新读取完整记录；一年后的日期仍可通过月历选择。

### 大列表与外观

- 提醒中心每页40条，避免一次创建数百个开关。
- 项目进度由SQLite聚合，详情先显示40个子任务，更多内容进入分页子任务页。
- 外观设置增加“紧凑列表与表格”，减少卡片、表格留白；触控区域仍至少48dp。
- 自定义类型显示图标、名称及颜色标记，文字仍使用主题前景色。
- 壁纸仅在文件变化时重新采样解码，最大边约1400像素；调整透明度复用位图。
- 动态背景不再每帧读取偏好或查询省电状态，后台停止动画。

### 同步与数据保留

- 回传Windows时优先读取当前远端行，保留未映射字段及原通知规则扩展，减少编辑普通字段时误覆盖其他数据的机会。
- Yjs缓存优先使用同目录原子替换，再提交SQLite同步基线。
- 发送慢时控制待发送队列，不持续堆积；输入仍按既有限额处理。
- 系统停止Job时尝试中断工作并关闭引擎／连接；同一服务只处理一项同步，离线修改保留供下次继续。
- 可以切换到已经登录的DayFlow或已经连接的TaskFlow，无需重新输入密码。断开非当前Windows连接不会关闭另一个服务的自动同步。
- 勾选完成前重新读取最新记录，避免拿旧列表快照覆盖刚同步的备注等字段。
- 服务器超时和AI超时使用各自的错误说明。

## 使用与边界

Android版本码110，APK可覆盖1.0.0或更早版本，签名及应用ID不变。TaskFlow连接步骤仍见[1.0.0连接说明](Android-1.0.0.md)。

Windows原版没有笔记页面及单次重复实例管理，扩展数据仍只在Android呈现；不宣称已改变Windows的功能。TaskFlow同步需要支持JavaScriptSandbox的较新系统WebView。云端、Windows、AI、天气依旧可选，不影响离线核心功能。

保留既有数据／同步安全体积限制；大工作区的实际内存和系统省电行为需用户实测。这些是代码中的资源改进，没有声称测得某个内存或耗电数字。

本次按用户要求只编译和发布，不运行自动测试、模拟器、实机、双机、实际云服务器或真实付费AI调用。三个发布阶段到此完成，后续依据用户反馈继续修正。
