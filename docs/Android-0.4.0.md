# Android 0.4.0：内置 Markdown 编辑器与桌面主题图标

## 内置编辑器

使用现成的 **MarkdownEditText 1.1.3**：https://github.com/YahiaAngelo/MarkdownEditText ，Apache 2.0。笔记改为独立全屏编辑页，不再使用日程表单。

- **编辑**：原生可视编辑区和组件自带格式栏，支持加粗、斜体、删除线、列表、编号和待办项。
- **源码**：直接编辑 Markdown 原文。复杂格式默认进入源码模式，避免富文本往返转换丢失格式。
- **预览**：离线原生 TextView 渲染。
- **保存**：顶部或底部“保存”；通过应用内返回按钮离开时也保存。旋转／重建时保留内容。杀进程前未保存的草稿不保证恢复。

已有图片笔记的附件继续保留，可从笔记详情查看。

## 真正的 .md 文件

每篇笔记在应用私有目录 `files/notes/<事项ID>.md` 保存 UTF-8 Markdown。旧笔记在首次启动后台转换；原数据库不删除，继续保存标题、置顶、修订、冲突和同步元数据。

文件、云端或局域网合并得到的笔记也生成同样的 .md 文件。修改、删除和从笔记转为待办时同步维护文件。私有目录无需存储权限；普通文件管理器通过导出获取副本。

## 导入导出

- 编辑页点 **导出 .md**：直接导出当前内容，包括尚未保存的文字；系统文件选择器决定保存位置。
- 详情页点 **导出 .md 文件**：导出已保存内容。
- 笔记列表点 **导出全部 .md**：生成 ZIP，每篇为独立 .md 文件，文件名附带 ID 防止同名覆盖。按篇写入，不把全部笔记读入内存。
- 列表点 **导入 .md**：读取 UTF-8 文件并创建可同步笔记。单次导入暂限48KiB，单条同步记录继续受64KiB上限约束。

正文不注入应用专属格式。旧图片笔记的附图以 Markdown data URI 写入 .md；其他编辑器是否显示内嵌图片取决于其支持。置顶／修订等元数据留在数据库；完整同步仍使用 .dayflow 文件或服务器。

## 桌面应用图标

启动图标改为自适应图标。Android 12+ 彩色图标取系统强调色，Android 13+ 提供 monochrome 图层。

系统主题图标需要启动器支持，并在系统／启动器中启用“主题图标”；配色由系统控制。旧系统使用备用配色。应用内继续使用原生主题。

## 发布状态

可覆盖安装原版本，沿用同一发行证书与同步协议。Windows 和服务端本次未修改，继续提供0.3.0文件及原 Windows 更新清单。

同步接口说明见 [客户端同步 API](客户端同步API.md)。按用户要求只编译打包，不运行测试、模拟器或 Lint。
