# Android 1.1.1

本版仅修改 Android，Windows 不修改；沿用原有可选同步服务。

## 日期与界面

月历和所有日期选择入口改用有界原生网格，去除原分页日历的测量与重复刷新路径。选择年月、日期后确认；支持1901–2099年。修正农历节气空值处理。没有设备崩溃日志，未做实机复现，具体闪退修复效果由用户确认。

笔记保存、导出改为弹性宽度，按钮文字单行横排。系统边距统一由根布局处理，底部导航使用自适应高度，避免重复底边距挤压导航标签；横屏同时避让刘海。

## 时间与提醒

事项支持仅开始、开始＋持续分钟、开始＋结束。结束可留空，不强制补造结束时间。持续分钟1–525600；AI可提取明确时长，未知信息保持空白。传往TaskFlow的无结束事项使用endAt=null。

提前提醒直接在主编辑页设置，支持0（准时）及多个逗号分隔分钟，最多5个，范围0–525600。可选通知、闹钟响铃、两者同时。时间、提醒方式及偏移分钟随记录同步，各设备自行调度，可能分别提醒。

闹钟采用AlarmManager.setAlarmClock；Android12+需允许精确闹钟，同时开启通知以显示停止按钮。提醒权限页提供系统入口。未授权精确闹钟时降级普通系统调度通知，可能延迟。普通通知如有精确权限则精确定时，否则按系统调度。

响铃时才启动媒体前台服务，最多2分钟，通知中可停止；不常驻轮询，不强行覆盖勿扰或音量设置。修改、完成、取消、删除后重新调度；接收时核对当前时间与偏移，忽略过期计划。重启、时区变化、应用升级后重建最近100个提醒。

系统机制参考：https://developer.android.com/develop/background-work/services/alarms

## AI截图课表

课表页或课表编辑页 → AI截图识别课表 → 选择截图 → 第1周周一、学期周数及可选节次对照 → 开始识别。此操作将截图及说明发送到用户配置的图片模型，不自动上传其他内容，不自动切换厂商或密钥。

截图按像素采样至最多400万像素、最长边约2800像素，JPEG请求上限2MiB，完成后释放Bitmap。适配OpenAI兼容Chat Completions的image_url请求；文字模型无法识图时需在设置更换支持图片的模型。

返回最多80条课程，原生可编辑表格每页20条；可改名称，点击星期/时间修改周次、地点、节次、单次日期、开始、结束或持续分钟，支持补充和删除课程。未知周次、星期及开始时间必须校正，不猜测学校作息。结束可空；持续分钟与结束时间二选一。单双周及指定周次可解析，跨天课程可使用持续分钟。

确认后原子创建最多4000次课程，出现在对应日期待办中并按原有机制同步。可以批量开启课程提醒。相同名称、日期、开始时刻及地点的已有记录（包括删除标记）跳过，避免重复和覆盖手工修改。

识别结果与已确认的行修改保留在本机私有课表草稿，课表页可恢复；正式导入后删除草稿。草稿不含密钥和图片，正式课程参与同步。

## 群聊收集与小组件

设置 → 通知收集：允许系统通知访问，启用收集，填写指定群名，每行一个。可用QQ|群名、微信|群名、TIM|群名限定应用。群名按通知会话标题精确匹配，不在正文搜索；支持发送者（群名）样式。

指定群默认收集全部通知，也可只保留日程关键词。留空群名沿用原关键词筛选；其他邮件来源仍按关键词筛选。MessagingStyle通知按最多20条结构化消息提取并去重，每次通知总文本最多12000字符，使用有限队列；不后台启动AI。

系统没有发出的通知、静音群、隐藏内容或历史聊天均无法读取；不使用Shizuku绕过其他应用私有数据。

自动收集记录为inbox、confirmation_status=pending。桌面小组件显示待确认数及最新内容，点击进入确认，不当作已确认任务；设置 → 桌面小组件可关闭此显示。小组件空间不足时减少日程行，避免挤压。群筛选规则是本机配置，收集的记录参与同步；确认保存后标记confirmed并转换为任务/日程/课程。

## 构建与实测边界

只执行Release编译和签名打包；按用户要求未运行测试、Lint、模拟器、实机、付费AI调用或真实群聊/双机连接。闹钟在具体机型的省电策略下、群通知标题格式、图片模型效果及UI实际显示请用户实测。
