# Android 0.5.0：连接、导航与 Markdown 编辑改进

## 登录失败保留输入与云端连接

修正异步任务发生异常后仍执行成功跳转的问题。登录失败留在服务器账号页，地址、用户名、密码与邀请码不重置，页内显示错误；只有成功后才进入同步页面。已保存的账号与本地数据不会因为失败被清除。

服务器地址支持域名／IP 与端口：无协议的域名默认 HTTPS，局域网私有 IP 默认 HTTP；末尾误填 `/v1`、`/v1/sync`、登录路径或 `/health` 会规范化。反向代理子路径可保留，例如 `https://host/dayflow`。

同源重定向及同主机 HTTP→HTTPS 升级可跟随，拒绝把密码或 token 跟随重定向发送到其他主机。错误区分 DNS、端口连接、超时、TLS 和返回网页／非 JSON，HTTP API 错误显示服务端说明。

账号页面提供“检查服务器连接”，由用户点击后验证 `/health` 的 `service=dayflow` 和 `protocol=1`。手机的 localhost 指手机本身；局域网连接应填服务器的局域网 IP。本轮没有访问用户实际云服务器，部署端口／证书／反向代理仍需根据实机提示确认。

## 完全移除顶栏

整条应用标题栏从布局中移除。页面返回使用系统返回键／返回手势。页面自身的操作按钮保留，重复的顶栏按钮删除；笔记保存、导出、撤销、重做和公式集中在编辑区最上面。

底部导航在同一 Activity 内只创建一次，固定高度，不随每次切换重新创建。异步进度改为覆盖内容的细进度条，不插入布局挤动内容。关闭会改变选项宽度的导航平移动画。

## AI 详细配置

厂商与模型改为原生下拉选择，模型仍可手输。预设包括 DeepSeek、阿里云百炼、Kimi、OpenAI 和自定义。

支持接口根地址／完整 chat/completions 地址、API Key、模型列表获取、Temperature、Top P、输出 Token 上限及参数名、响应超时10–300秒、思考模式、额外 JSON 请求参数。留空的生成参数不强制发送。

额外 JSON 不能覆盖核心的 model、messages、stream 字段；其他参数是否受所选模型支持由服务商决定。密钥按接口地址分别加密保存，切换服务商不会误用其他地址的密钥。AI 参数与密钥仍为本机配置，不随日程同步。

## 笔记撤销、公式与文件

- 顶部集中提供保存、导出、撤销、重做和插入公式。
- 撤销／重做记录正文 Markdown 快照，600毫秒归组，最多30份且合计约512KiB；离开编辑页后不保留撤销历史。恢复历史使用源码模式，保留格式。
- 公式在源码中保留，支持 `$E=mc^2$` 行内公式与独占行 `$$` 包裹的公式块，在预览／笔记详情本地渲染。代码块不按公式处理。
- 列表保留“导入 .md”，支持 UTF-8 文件；原有单篇48KiB导入、单条64KiB同步限制继续生效。
- 注册系统 Markdown 的查看／编辑／分享处理器。文件管理器中选择日栖打开，可在系统允许时设为默认；应用不能代替用户强制改默认关联。
- 来源授予写权限时，“保存”写回原文件；只读来源保存到应用笔记，也可以导出副本。反向写入失败时保留已经保存的应用笔记。
- 同一文档 URI 保留本机 ID 映射；若外部文件与应用笔记均已变化，另建副本保留原笔记。URI／文件权限映射不上传服务器。

公式使用未修改的原生 JLaTeXMath Android，通过上游的独立模块链接例外使用；对应源码与许可随 Release 提供，不把它重新标为 MIT。公式后台渲染采用单线程、有界队列，空闲后退出。

## 任务管理补齐

- 今天 → “搜索、项目与全部安排”进入二级管理页，首页仍只显示今天。
- 原生日程编辑增加长任务；更多选项可配置所属长任务、自定义类型、计划／完成／取消状态、全天、独立截止日期。
- 长任务详情显示子任务及完成进度，可直接新建子任务。
- 设置 → 任务类型支持最多三级分类、继承基础行为、图标／颜色、改名、归档及同类合并。合并在事务内分批迁移关联事项。
- 每日／每周／每月重复改为按规则展开；每周可选择多个星期，可设结束日期。月度遇到不存在的日期跳过该月。
- 可以编辑单次重复实例，或从实例进入整个系列。完成／删除单次不会影响整个系列，覆盖记录随数据同步。
- 全局搜索包括标题、正文、地点及类型名，200ms合并输入、60条分页；保留表格30条分页编辑。
- 集中提醒页可开启／暂停对应事项；支持最多5个提前分钟设置。通知点击打开准确的事项及重复实例。
- 新增日／周／年浏览、全年日期预览、默认启动页／默认日历视图，以及系统打印／保存PDF入口。
- AI 待确认草稿增加类型行为、独立截止日期、全天、重复星期、提醒与已有类型匹配。

完整对照见 [TaskFlow功能对照](TaskFlow功能对照.md)。用户明确不需要设备配对，未加入配对码／二维码或本机锚点入口。

## 内存与调度

年历用单个 Canvas 绘制，避免365个日期分别创建视图。未来重复实例按查询展开，不提前写入大量记录；修改、完成和删除时才落库。日期查询和项目子任务有上限，搜索／表格分页。通知使用系统 Alarm，最多保留最近100个提醒并每日更新，不增加常驻进程。笔记快照在正文副本上序列化，避免影响原编辑器的列表监听。

## 发布与验证

Android 可覆盖原版本，本地数据库自动迁移到 schema 3，保留既有数据。服务端增加 `kind=type` 以及健康检查能力标记，传输协议仍为 v1；使用自定义类型前请升级配套服务端。

Windows 本次不修改、不发布新 Windows 二进制，下载页如提供 Windows 文件，仍为之前的0.3.0包及原更新清单。后续连接目标是用户提供的 TaskFlow Windows 端，需要单独做它的协议适配，当前版本尚不能连接它的 Yjs／WebSocket 同步锚点。

按用户要求只做编译与发布打包，没有运行自动测试、模拟器、实机测试、实际云端连接或付费 AI 调用；交互效果与设备文件管理器兼容性由用户反馈。
