# Android 发布阶段

按用户要求顺序发布三次，不修改 Windows 端代码：

1. **0.5.0**：当前 Android 交互修正和 TaskFlow 业务功能补齐，配套 DayFlow 服务端支持类型定义。已编译并发布v0.5.0。
2. **1.0.0**：已编译并发布v1.0.0，增加直连现有TaskFlow Windows的密码鉴权、Yjs和字段映射，保留离线／文件模式。
3. **1.1.0**：增加笔记草稿、远期折叠、提醒／子任务分页、紧凑布局、壁纸复用和同步中断处理，完成第三次发布。

后续版本不能只改版本号：每次必须有实际功能或稳定性改进、对应源码及可安装 APK。仍遵守用户要求，只编译打包，不运行自动测试、模拟器、实机或付费 AI 调用。
