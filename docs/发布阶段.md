# Android 发布阶段

按用户要求顺序发布三次，不修改 Windows 端代码：

1. **0.5.0**：当前 Android 交互修正和 TaskFlow 业务功能补齐，配套 DayFlow 服务端支持类型定义。编译后发布。
2. **1.0.0**：完成剩余核心功能，适配连接用户提供的 TaskFlow Windows 同步服务；明确两个协议的数据映射，保留离线／文件模式。
3. **1.1.0**：在上述基础上完善操作体验、稳定性、同步恢复和资源占用，再发布。

后续版本不能只改版本号：每次必须有实际功能或稳定性改进、对应源码及可安装 APK。仍遵守用户要求，只编译打包，不运行自动测试、模拟器、实机或付费 AI 调用。
