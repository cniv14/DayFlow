# TaskFlow 功能对照：以 Android 为主

参考文件：用户提供的 `taskflow-src.zip`（TaskFlow 0.9.1）。SHA-256：`6f8d8dbc732fee9890679eaff5f8dad3512845a92206a2be26a5c05319d8ce3f`。

本表对照压缩包中的界面及其实际调用的数据代码。没有运行压缩包脚本，没有复制其代码。压缩包根目录未提供 LICENSE；DayFlow 的实现沿用自身原生 Android 架构。下表“已接入”表示代码和入口已完成，不表示经过实机测试。

用户后续明确：主要做 Android，设备配对不需要。因此不纳入配对码、二维码和 Windows 本机锚点扩展。Android 继续使用可选服务器账号或 `.dayflow` 文件同步。

## Android 额外保留的核心功能

今天首页、行式表格编辑、课程 CSV／ICS 导入、QQ／微信通知收集、截图／图片输入、Markdown 编辑器及 `.md` 文件、撤销／公式、系统日历与闹钟入口、桌面小组件、深色主题和系统强调色均继续保留。整条应用顶栏不恢复。

## 平台适配与边界

TaskFlow 的 Windows 标题栏、最大化／最小化、可拖动侧栏宽度属于桌面外壳；Android 使用原生系统返回和底部导航，不照搬桌面窗口。压缩包中标注占位的截图按钮、快捷键配置和未实现的动态字段 UI，不计作已经完成的业务功能；DayFlow 自身已有截图输入。

Android 本次只编译，不进行自动测试、模拟器、实机、云服务器或真实付费 AI 调用。系统打印、通知投递、默认 Markdown 文件处理与键盘体验需由用户实测。

为控制内存，搜索每页60条、表格每页30条，日期查询最多500条落库事项及总计1000条展开结果；单次展开最多跨732天。提醒保留最近100个系统 Alarm，并每日更新调度窗口；Doze及厂商省电策略可能延迟投递。项目详情最多读取1000条子任务，不适合作为无限规模项目看板。

Windows 本次不修改；后续只做 Android 到用户 TaskFlow Windows 端的连接适配。旧 DayFlow Windows 客户端尚不支持新类型定义。服务端需升级到本次配套版本以接收 `kind=type`。客户端保留原 v1 传输结构；不与 TaskFlow 的 Yjs 存储或其 WebSocket 协议互通。
